RELEASE NOTES: Version 2026.10.31.0

RELEASE HIGHLIGHTS — DEEP ARCHITECTURAL REFACTORING (C++/Qt6 -> Rust/egui)

This milestone release of Huginn Sentinel consolidates a complete software engineering and architectural refactoring: the legacy codebase developed in C++17 and Qt 6 (Huginn_cpp) has been entirely redesigned, rewritten, and modernized into a pure native Rust ecosystem (Edition 2021) powered by a hardware-accelerated immediate-mode graphical user interface via egui/eframe 0.37 (HuginnSentinel_rs).

Far beyond a simple syntactic translation between languages, this migration represents a foundational structural transformation across all subsystems — from the compilation pipeline and self-contained binary distribution to compile-time memory safety, lock-free concurrency, asynchronous transactional SQLite WAL persistence, a 17-chart GPU vector analytics engine, independent native Win32 multi-viewport modeless child windows, and a virtualized 58-column forensic spreadsheet supporting arbitrary runtime row and column freezing (pinning).


IN-DEPTH REFACTORING BREAKDOWN: FROM C++/Qt6 TO RUST/EGUI

1. Toolchain, Build System, and Self-Contained Binary Distribution (CMake/windeployqt -> Cargo/LTO)
- Legacy Architecture (C++17 / Qt 6): Depended on a monolithic CMakeLists.txt script with over 1,350 lines, Meta-Object preprocessors (CMAKE_AUTOMOC, CMAKE_AUTORCC, CMAKE_AUTOUIC), heavy dynamic linking against ten external Qt 6 framework modules (Core, Gui, Widgets, Sql, Xml, Concurrent, OpenGL, OpenGLWidgets, Quick, and Qml), and mandatory post-processing via windeployqt to package dozens of runtime DLLs, platform plugins (qwindows.dll), SQL drivers (qsqlite.dll), and compiled translation binaries (.qm).
- New Architecture (Rust / Cargo): Managed declaratively via Cargo.toml with an optimized production profile (lto = true, codegen-units = 1, opt-level = 3, strip = true). Compiles directly into two portable, self-contained native executables (`huginnsentinel.exe` for the Desktop GUI and `huginnsentinel-cli.exe` for the command line), eliminating 100% of Qt DLLs, runtime version conflicts, and fragile packaging workflows.

2. Cohesive Domain Modularity vs. Numbered Procedural Fragmentation
- Legacy Architecture (C++17 / Qt 6): Concentrated responsibilities within a god-object `InterfaceMonitor` (`QMainWindow`) artificially dismembered across dozens of sequentially numbered files (`gmet_01..47`, `gbank_01..20`, `gob_01..13`, `gst_01..18`, `ui_01..15`, `gmui_*`, `secui_*`), hindering traceability, evolutionary maintenance, and isolated unit testing.
- New Architecture (Rust): Structured into clean, cohesive, and strongly decoupled domain modules (`core`, `services`, `security`, `data`, `tools`, `locale`, `ui`, `utils`, and `cli`), with explicit data ownership boundaries and auditable internal APIs.

3. Graphical Interface Paradigm: Retained Mode (QtWidgets/QML) -> GPU Immediate Mode (egui/eframe 0.37)
- Legacy Architecture (C++17 / Qt 6): Based on a retained-mode model of `QObject`/`QWidget` pointer trees, coupling through `Q_OBJECT` macros (signals/slots), and hybrid composition between `QWidgets` and `QQuickWidget`/`QML`, resulting in high baseline RAM consumption and state synchronization overhead between model and widgets.
- New Architecture (Rust / egui): Hardware-accelerated immediate-mode vector rendering (OpenGL/Glow/WGPU) directly from the application's immutable/controlled state on every frame, providing near-instantaneous startup, minimal memory consumption, zero UI state desynchronization, and automatic real-time adaptation to Windows 11 native Light and Dark themes.

4. Native Win32 Multi-Viewport Modeless Child Windows and Dynamic OS-Level Z-Order Management
- Legacy Architecture (C++17 / Qt 6): Secondary dialogs inherited focus and hierarchy limitations from `QDialog`/`QWidget`, requiring global event filters (`eventFilter`) and dynamic properties (`linceuManagedChildDialog`) to work around overlap blocking and loss of focus between windows.
- New Architecture (Rust / Win32 Multi-Viewport): All 13 auxiliary windows (About, Help, User Manual, Statistics, Alert Center, Session Center, Recovery/Quarantine, Multi-Directory, Advanced Filters, Evidence Export, Configure Columns, Configure Colors, and Pop-up Notifications) operate via `show_viewport_immediate` as native, independent Windows 11 `HWND` viewports. They feature standard operating system title bars (Minimize 🗕, Maximize/Restore 🗖/🗗 integrated with Snap Layouts, and Close 🗙), unrestricted movement outside the main window across multiple monitors, native OS Z-Order elevation on click/focus, and a smart footer taskbar dynamically displaying the exact count of open child windows ("1 Window:", "2 Windows:", "3 Windows:", etc.) with immediate focus restoration buttons.

5. New Virtualized Forensic Spreadsheet (`SpreadsheetGrid`) with Arbitrary 2D Row & Column Freezing
- Legacy Architecture (C++17 / Qt 6): Utilized `QTableView` coupled with `EventTableModel` (`QAbstractTableModel`) with repetitive `QVariant` conversions, suffering performance degradation under large event volumes and lacking the capability to freeze arbitrary rows or columns chosen by the auditor.
- New Architecture (Rust / SpreadsheetGrid): Custom-built spreadsheet engine featuring synchronized 4-quadrant rendering (Top-Left, Top-Right, Bottom-Left, and Bottom-Right) with `O(visible_rows)` virtualization:
  * Flexible Freezing (Pinning) of Any Row: Through the "Settings -> Freeze Rows" menu or the context menu (right-click), the user can define whether the 1st row (Column Headers) remains fixed or scrolls vertically, as well as pin or unpin any specific data row in the table (via direct selection, row click, or entering numbers/ranges such as `1, 5, 10-12`).
  * Flexible Freezing (Pinning) of Any Column: Through the "Settings -> Freeze Columns" menu, table toolbar, or right-clicking on a header, the user can pin or unpin the 1st numerical column (`#`) and any combination of the 58 metadata columns to remain stationary on the left during horizontal scrolling, with automatic persistence in `painel_fixo_config.json`.
  * Complete Excel-Grade Interactivity: Single-cell, rectangular drag/Shift, whole-row, whole-column, and Select All selection modes; continuous edge resizing with double-click AutoFit; adaptive zebra striping; chromatic badges per operation; and rich contextual tooltips.

6. Strict Static Typing Across 58 Forensic Categories (`EventModel` vs. `QVariantMap`)
- Legacy Architecture (C++17 / Qt 6): Passed metadata between collectors, database, and interface using loosely typed `QVariantMap` dynamic maps indexed by literal strings, vulnerable to divergent keys, costly implicit conversions, and silent runtime failures.
- New Architecture (Rust): Replaces all dynamic dictionaries with the strongly typed `EventModel` struct and exhaustive `OperationType` enum. Extracts and audits 58 forensic columns before and after each modification: true MIME detection via Magic Numbers, pure-Rust cryptographic SHA-256, SHA-1, and MD5 hashes, Shannon entropy calculation, PE header/section structural analysis, native Authenticode digital signature validation via Win32 `WinTrust`, line and word counts, compression ratio and internal item inspection of ZIP archives, image dimensions, media duration, actor process attribution, baseline drift status, and quarantine custody tracking.

7. Compile-Time Memory Safety and Lock-Free Concurrency
- Legacy Architecture (C++17 / Qt 6): Manual and semi-automatic pointer management across `QThread`, `QtConcurrent`, and asynchronous signals, requiring constant vigilance against data races, dangling pointers, and lock contention on the main GUI thread.
- New Architecture (Rust): Mathematical guarantees of the Rust compiler (`Send` + `Sync` + borrow checker) eliminate memory corruption, *use-after-free*, and *data races* without any garbage collector (zero GC). Windows kernel monitoring via `ReadDirectoryChangesW` (`notify 8.2`) and high-throughput recursive scanning communicate with the GUI through lock-free `crossbeam-channel` queues and ultra-lightweight `parking_lot` primitives, guaranteeing absolute UI smoothness even under massive disk event storms.

8. Decoupled Transactional Persistence (Embedded SQLite WAL + `DbWriter` vs. `Qt6::Sql`)
- Legacy Architecture (C++17 / Qt 6): Based on `QSqlDatabase` and `QSqlQuery` dependent on external drivers and subject to strict Qt SQL thread affinity restrictions and synchronous I/O blocking.
- Nova Architecture (Rust / rusqlite): Incorporates the C SQLite engine compiled statically within the executable itself (`rusqlite` with the `bundled` feature), operating in `WAL` (`Write-Ahead Logging`) mode managed by a dedicated background asynchronous `DbWriter` thread that batches transactions into `%LOCALAPPDATA%\HuginnSentinel\monitoramento.db` with zero UI latency.

9. Deterministic Security Engine, Cryptographic Baseline, and Atomic Quarantine
- Legacy Architecture (C++17 / Qt 6): Heuristic rules scattered across UI subclasses and secondary threads, creating inconsistent concurrent evaluations, without deterministic execution guarantees, lacking atomic quarantine isolation with custody hashes, and without structured cryptographic baseline verification.
- New Architecture (Rust): Deterministic engine with continuous evaluation of 6 canonical heuristic rules (`SEC-R01` through `SEC-R06`) for autonomous detection of ransomware (entropy spikes + mass rename patterns), suspicious double extensions, anomalous script/executable drops, and integrity violations, SHA-256 cryptographic baselines for compliance drift auditing, atomic quarantine isolation with hash-verified `.meta` rollback manifests, and sealed ZIP forensic evidence package export.

10. Native GPU Vector Charting Engine (17 Analytical Charts in `egui::Painter`)
- Legacy Architecture (C++17 / Qt 6): Fragmented across overlapping implementations (`LgplChartModel`, `RasterChartView`, `WidgetChartView`, and `QuickChartItem`), creating graphic complexity and CPU repaint overhead.
- New Architecture (Rust): Unified vector analytics engine rendered directly via `egui::Painter` with 17 interactive charts (Treemap, Bars by Type, Bars by Extension, Event Timeline, 24-Hour Hourly Histogram, 80/20 Pareto Curve, Multi-Series Line Chart, Log-Scale Boxplot, Operational Radar, Multi-Dimensional Risk Radar, 7×24 Activity Heatmap, Time×Size Scatter Plot, Sankey Relational Flow, Volumetric DotPlot, and Directory Hierarchy Tree), alongside direct offscreen rasterization for high-resolution PNG export.

11. Embedded Internationalization (i18n) with Instant Runtime Dynamic Translation
- Legacy Architecture (C++17 / Qt 6): Depended on the Qt Linguist `lupdate`/`lrelease` workflow and external loading of binary `.qm` translation files.
- New Architecture (Rust / Localizer): All 6 complete dictionaries (`pt_BR`, `en_US`, `es_ES`, `fr_FR`, `it_IT`, and `de_DE`), containing more than 2,000 keys each, are compiled directly into the binary via `include_str!`. The system natively detects the Windows 11 display language (`GetUserDefaultUILanguage`) on first run and allows switching the entire interface language — including menus, columns, frozen panels, charts, footer, and context menus — instantaneously at runtime, with zero application restarts.

12. Headless CLI Utility (`huginnsentinel-cli.exe`), Native CI/CD, and Sovereign Privacy
- Legacy Architecture (C++17 / Qt 6): Total lack of an autonomous CLI utility and mandatory dependency on initializing the Qt `QApplication` graphical stack, preventing headless execution on servers, CI/CD integration pipelines, or terminal script automation.
- New Architecture (Rust): Autonomous and ultra-fast command-line utility (`huginnsentinel-cli.exe`) based on `clap`, sharing 100% of the native forensic engine for automated audits via PowerShell, Windows Task Scheduler, and DevSecOps pipelines (`scan`, `monitor`, `metadata`, `baseline`, `alerts`, `quarantine`, `sessions` with Text, JSON, and CSV outputs), with a strictly 100% Local-First and Offline architecture: zero telemetry, zero network calls, and 100% deterministic analytics without dependency on external AI/LLM models.
